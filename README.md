# MLOps Major Assignment

This project demonstrates an end-to-end MLOps pipeline using:

- Python
- scikit-learn
- Olivetti Faces dataset
- DecisionTreeClassifier
- GitHub Actions CI/CD
- Flask web application
- Docker
- DockerHub
- Kubernetes

## Branches

- main: Initial repository setup
- dev: Model training, testing, and CI workflow
- docker_cicd: Flask app, Dockerfile, Docker image, and Kubernetes deployment
